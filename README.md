# Kiroku (記録) Notes

🇨🇳 **中文**

这是一款完全本地化的笔记本应用，不上传、不同步、不依赖云端。所有内容仅存储在你的电脑中，真正属于你自己，适合重视隐私与数据安全的用户。

🇺🇸 **English**

This is a fully local note-taking app with no cloud upload, no synchronization, and no external dependencies. All data stays on your device, giving you complete ownership and maximum privacy.

## Features
- **Privacy First**: All notes are stored in your browser's `localStorage`.
- **Markdown Support**: Write with ease using Markdown syntax.
- **Anime Aesthetics**: A beautiful, minimalist design inspired by Makoto Shinkai's sky and soft light.
- **Split View**: Real-time preview while you edit.
- **Fast Search**: Quickly find your notes by title or content.
